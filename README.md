# 📡 ２陸技 無線工学A 合格アプリ

令和8年7月期受験向け、1時間/日で合格を狙う合格戦略型学習アプリ。

## アプリの特徴

- **直近7年分の過去問解析**：令和元年7月～令和7年7月の13回分を重点分析
- **3段階レベル制**：🔥 鉄板(Lv1) → ⭐ 決め打ち(Lv2) → 📗 仕上げ(Lv3)
- **本番形式に対応**：A問題(5択×20問×5点) + B問題(穴埋め・正誤×5問×1点) = 125点満点、75点合格
- **計算問題コツ付き**：数学が苦手でも使える「電卓なしで解く型」を標準装備
- **オフライン対応**：単ファイルで外部依存なし、スマホでもそのまま使える

## 使い方

ブラウザで開くだけ。ネット接続不要。

- **ホーム**：進捗確認・学習ロードマップ
- **カード**：暗記カード105問（Lvと分野で絞り込み可）
- **クイズ**：本番形式で練習
- **模試**：125点満点の模擬試験（A20問＋B5問）
- **攻略**：出題枠マップ・頻出ランキング・計算8型

## 学習時間の目安

- **Lv1鉄板** 37枚 → 約45～55点分（4日で1周）
- **Lv2決め打ち** 47枚 → 累計65～75点（さらに4日）
- **Lv3仕上げ** 21枚 → 75点超え＝合格圏（さらに2日）

合格判定：模試で2回連続75点以上
